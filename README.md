# Skills Repository

A collection of AI skills for image processing and visual transformation.

## Included Skills

### 1. travel-zine-map-overlay
- **Description**: Transform travel photographs into editorial photography and indie travel zine visual pieces by compositing a transparent, minimalist geographic map overlay onto the original image.
- - **Location**: `skills/travel-zine-map-overlay/SKILL.md`
 
  - ### 2. cartoonskill
  - - **Description**: Transform a photograph into a vertical split diptych pairing the original photo on the bottom with a warm, hand-drawn color marker cartoon illustration and a short handwritten English quote on textured cream paper on top.
    - - **Location**: `skills/cartoonskill/SKILL.md`
     
      - ## Directory Structure
     
      - ```
        skills/
        ├─ README.md
        ── skills/
            ├── cartoonskill/
            │   └── SKILL.md
            └─ travel-zine-map-overlay/
                └── SKILL.md
        ```

        ## How to Add or Download Skills

        ### Using `npx skills`

        To add individual skills directly to your project:

        - **Add `travel-zine-map-overlay`**:
        -   ```bash
              npx skills add wudiares/skills --skill travel-zine-map-overlay
              ```

            - **Add `cartoonskill`**:
            -   ```bash
                  npx skills add wudiares/skills --skill cartoonskill
                  ```

                ### Cloning the Repository

                To clone the full repository to your local machine:

                ```bash
                git clone https://github.com/wudiares/skills
                ```
